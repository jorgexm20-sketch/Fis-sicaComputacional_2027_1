# Computational Physics & Numerical Methods

This repository contains exercises, numerical implementations, and computational projects developed for the course **Computational Physics**, offered at the Faculty of Sciences, UNAM.

The course focuses on the theoretical foundations and computational implementation of **numerical methods for solving problems in physics and applied mathematics**, with particular emphasis on scientific computing using **Python and Jupyter notebooks**.

Topics covered include:

* Scientific computing with Python
* Numerical errors and floating-point arithmetic
* Numerical differentiation
* Numerical integration
* Trapezoidal and Simpson's rules
* Gaussian quadrature
* Interpolation and curve fitting
* Numerical linear algebra
* Gaussian elimination and pivoting
* LU decomposition
* Matrix inversion
* Eigenvalue and eigenvector problems
* Numerical solution of the stationary Schrödinger equation
* Nonlinear equations
* Relaxation methods
* Bisection method
* Newton–Raphson method
* Numerical optimization
* Gradient descent and Gauss–Newton methods
* Ordinary differential equations
* Euler method
* Runge–Kutta methods
* Dynamical systems
* Simple and double pendulum simulations
* Lotka–Volterra systems
* Lorenz system and chaotic dynamics
* Partial differential equations
* Finite-difference methods
* Laplace and Poisson equations
* Diffusion and heat equations
* Wave equation
* Numerical stability
* Random processes and random number generation
* Monte Carlo integration
* Monte Carlo simulations
* Applications to statistical physics
* Introductory data analysis and machine learning

Most of the computational work is implemented in **Python**, using tools such as **NumPy, SciPy, Matplotlib, pandas, and Jupyter**.

The repository emphasizes the connection between **mathematical modeling, numerical analysis, and computational experimentation**, applying numerical algorithms to physical systems that cannot always be treated analytically.

Particular attention is given to understanding the **accuracy, convergence, stability, and computational limitations** of numerical methods, rather than relying exclusively on high-level numerical libraries.
